# Portfolio Website 🚀

A modern, responsive personal portfolio website built to showcase my data analytics projects, web applications, and video demos.

## 🛠️ Tech Stack & Tools
* **Frontend:** HTML5, CSS3
* **Design Concept:** Glassmorphism UI, Modern Responsive Layout
* **Hosting:** GitHub Pages

## 🌟 Features
* Clean and interactive landing page with smooth section navigation.
* Dedicated sections for **About**, **Skills**, **Projects**, and **Contact**.
* Direct links to GitHub repositories and professional contact channels.
